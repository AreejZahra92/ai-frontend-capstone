# AI Frontend Capstone — Development Environment Setup

**Role:** Frontend AI Engineering Intern, FlyRank

---

## Problem

The AI Frontend Capstone is part of my Frontend AI Engineering internship at FlyRank. Before I could work on the capstone, I did not have a development environment set up to build and collaborate on the project.

My first assignment was to set up the AI toolchain, Git, Cursor, and the project on my machine. That step mattered because all of these tools need to work together. If I skipped it, I would likely hit missing dependencies, Git problems, or AI tools that do not work as expected. That would slow me down and make it harder to follow the program’s workflow.

The capstone is structured step by step. I needed a working, version-controlled foundation before moving on to frontend implementation.

---

## What I Did (including my decisions)

I installed Git, Node.js, Cursor, and the other tools required for the internship. I created the GitHub repository for the project, initialized it locally, cloned the repo, ran `npm install` to install dependencies, configured Git, and pushed the initial project files. I kept the repository structure aligned with the project requirements so future assignments would be straightforward to continue.

I chose Cursor as my main editor instead of another code editor because it has built-in AI assistance, which matches the internship’s focus on AI-assisted development.

When I hit errors during setup, I used AI in Cursor, ChatGPT, and Claude to understand the setup process, troubleshoot problems, and explain what different tools and commands were for—including dependency installation, Git configuration, and why certain commands or files were needed. I still did the work myself: I followed the instructions, ran commands in the terminal, created and edited the required files, verified that things worked, and applied fixes based on the guidance I got. I treated AI as a learning and troubleshooting assistant, not as something to complete the assignment for me.

One real issue came up when the project would not start because dependencies were not installed yet. I saw an error that `next` was not recognized as a command. I checked the project setup, ran `npm install`, and after that I could run the project successfully.

I did not run into Git or GitHub problems during this phase.

To confirm the assignment was done, I checked that Node.js and Git were installed and working, `npm install` finished without errors, I could open the repository in Cursor, and the project ran after fixing the dependency issue. I also confirmed the GitHub remote was connected and I could push changes.

I started this work about a day into the internship and finished the environment setup by the end of that same day.

---

## What Came of It

I completed the AI toolchain and development environment setup assignment. I have a working development environment, a project connected to GitHub, and a base I can build on for the next capstone tasks.

I understand better now why environment setup comes before coding. Git, Node.js, project dependencies, and the editor all depend on each other. When something failed, I learned to troubleshoot instead of assuming the project itself was broken.

If I set up a similar project again, I would read the setup instructions carefully first, verify each step as I go, and commit to GitHub more often so progress is easier to track and mistakes are easier to recover from.

At this point the main frontend work is still ahead. I have been completing each deliverable in order. I want reviewers to see that I can set up a development environment correctly, follow technical documentation, configure the required tools, fix real setup issues, use Git and GitHub, and use AI to learn—not to skip the work. That foundation is what I needed to move on to the next assignment with confidence.
